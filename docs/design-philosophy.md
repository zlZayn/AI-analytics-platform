# 数据分析工作台设计哲学

## 边界

SQL 和 AI 负责业务语义、连接、过滤和聚合。图表接收结果集，只做确定、可测试、可解释的展示变换。任何排序、分箱、采样、类别合并或缺失值处理都必须在界面上说明。

推荐是建议，不是隐式决策。首次结果保持表格，用户主动选择建议后才切换图表；用户始终可以修改字段映射和显示选项。

## 稳定性

接口必须提供加载、成功、空、失败、取消和重试状态。旧的成功结果在重新执行时保留，并明确标记为旧结果。任何截断或采样都返回元数据，不允许静默丢失。

## 视觉

界面是面向重复工作的专业分析台：稳定的网格、明确的层级、紧凑但可读的间距、语义化颜色和低干扰网格线。产品采用唯一的专业亮色体系，页面、状态和图表颜色全部由 `src/app/globals.css` 的语义 token 管理，组件不得维护第二套颜色常量。颜色不能成为唯一编码；每个图表都提供 tooltip 和表格入口。
