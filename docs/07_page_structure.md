**MVP 阶段只保留 4 个核心页面**：

1. 连接管理 - 添加/编辑/删除数据库连接
2. AI 分析 - 自然语言查询
3. SQL 编辑器 - 手动编写 SQL
4. 保存的查询 - 查看历史查询
