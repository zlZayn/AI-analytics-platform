# 页面结构文档

## 一、页面总览

```text
┌──────────────┬──────────────────────────────────────┐
│              │                                      │
│   Sidebar    │          Content Area                │
│              │                                      │
│  Logo        │  [根据路由显示不同内容]               │
│  ──────────  │                                      │
│  当前连接    │                                      │
│  切换连接    │                                      │
│  ──────────  │                                      │
│  数据工作台  │                                      │
│  数据探索    │                                      │
│  查询管理    │                                      │
│              │                                      │
└──────────────┴──────────────────────────────────────┘
```

---

## 二、页面路由

| 路由 | 文件 | 功能 |
| :--- | :--- | :--- |
| `/` | `page.tsx` | 连接管理 (新建/编辑/删除) |
| `/workspace?connection=xxx` | `workspace/page.tsx` | 数据工作台 (SQL + AI) |
| `/explorer?connection=xxx` | `explorer/page.tsx` | 数据探索 (Schema 浏览) |
| `/queries?connection=xxx` | `queries/page.tsx` | 查询管理 (收藏 + 历史) |

---

## 三、页面跳转逻辑

```text
/ (连接管理)
  │
  ├── [选择连接] → /workspace?connection=xxx
  │
  ├── /workspace (数据工作台)
  │     │
  │     │  左: SQL 编辑器    右: AI 助手
  │     │  ─────────────────────────────
  │     │  AI 生成 SQL → 自动填入左边
  │     │  执行 SQL → 结果显示在下方
  │     │
  │     └── [保存] → /queries?connection=xxx
  │
  ├── /explorer (数据探索)
  │     └── [在工作台执行] → /workspace?connection=xxx&sql=xxx
  │
  └── /queries (查询管理)
        └── [执行] → /workspace?connection=xxx&sql=xxx
```

## 四、页面详细设计

### 1. 连接管理 `/`

管理 PostgreSQL 数据库连接。

```text
┌─────────────────────────────────────────┐
│  连接管理                    [新建]      │
├─────────────────────────────────────────┤
│  ┌───────────────────────────────────┐  │
│  │  ► 药店数据库                     │  │
│  │    localhost:5432/ai_analytics     │  │
│  │                    [进入][编辑][×] │  │
│  └───────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

### 2. 数据工作台 `/workspace`

核心工作区，SQL 和 AI 左右分栏。查询后自动收起编辑器，可视化区域更大。

```text
┌──────────────────────────────────────────┐
│  展开状态:                               │
│  ┌─────────────────────┬──────────────┐  │
│  │  SQL 编辑器          │  AI 助手     │  │
│  │  Monaco Editor       │  自然语言    │  │
│  │                      │  输入框      │  │
│  │  [执行] [清空] [保存] │  对话历史    │  │
│  └─────────────────────┴──────────────┘  │
├──────────────────────────────────────────┤
│  收起状态:                               │
│  [∨] SQL 编辑器  SELECT * FROM ...  [执行]│
├──────────────────────────────────────────┤
│  查询结果 (图表配置 + 渲染)              │
│  - 图表类型选择 (8 种)                   │
│  - 图例开关                              │
│  - 列映射槽位                            │
│  - 图表渲染                              │
└──────────────────────────────────────────┘
```

- 左: SQL 编辑器 (手动写 SQL)
- 右: AI 助手 (自然语言 → 自动生成 SQL 填入左边)
- 下: 结果面板 (图表类型选择 + 图例开关 + 列映射 + 渲染)
- 查询后自动收起编辑器，点击收起条可展开

### 3. 数据探索 `/explorer`

浏览数据库结构。

```text
┌──────────────┬──────────────────────────┐
│  搜索表...   │  [字段] [关联] [预览]    │
├──────────────┤                          │
│  dim_date    │  字段名    类型    可空   │
│  dim_member  │  ──────────────────────  │
│  dim_product │  id       bigint   N     │
│  fact_orders │  name     varchar  N     │
│  ...         │  ...                     │
└──────────────┴──────────────────────────┘
```

### 4. 查询管理 `/queries`

收藏查询 + 执行历史。

```text
┌──────────────────────────────────────────┐
│  [收藏] [历史]              搜索...      │
├──────────────────────────────────────────┤
│  会员统计                                 │
│  SELECT p.name, COUNT(m.id) ...          │
│                              [执行][复制][×]│
├──────────────────────────────────────────┤
│  OK  100 行  15ms                        │
│  SELECT * FROM fact_orders ...           │
│                              [执行][复制] │
└──────────────────────────────────────────┘
```

## 五、布局组件

### AppShell

顶层布局，包含 Suspense + ToastProvider + ConnectionProvider + Sidebar + Main。

### Sidebar

左侧导航，包含:

- Logo
- 当前连接信息 (从 URL 读取 connectionId)
- 导航菜单 (3 个页面: 工作台/探索/管理)
- 版本号

### ConnectionProvider

React Context，从 URL 读取 `?connection=xxx`，加载连接信息，提供给所有子组件。

### ToastProvider

操作反馈通知系统，提供 `useToast` hook。
