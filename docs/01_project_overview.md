# 通用型 AI 数据分析平台 - 项目概述

## 一、项目定位

### 项目名称

AI Data Analytics Platform (AI-DAP)

### 项目目标

构建一个支持 PostgreSQL 数据库接入的智能分析平台。

用户无需编写 SQL，通过自然语言即可完成：

- 数据探索
- 趋势分析
- 指标统计
- 图表生成
- 仪表板构建

系统通过自动解析数据库 Schema，结合 AI 理解用户意图，生成分析结果与可视化内容。

### 核心特性

1. **Schema 深度绑定** - 自动发现数据库结构，理解表关系
2. **AI 驱动分析** - 自然语言输入，智能生成 SQL 和图表
3. **安全可控** - AI 不直接操作数据库，所有 SQL 经过校验
4. **可视化丰富** - 多种图表类型，支持仪表板组合
5. **通用性强** - 可接入任意 PostgreSQL 数据库

## 三、架构设计

### 架构原则

#### 1. 简洁优先

AI 直接生成 SQL，系统负责安全校验和执行。

**流程**：

```text
用户输入 → AI 生成 SQL → 安全校验 → 执行查询 → 可视化
```

**避免过度设计**：

- ~~Analysis Planner~~
- ~~SQL Builder~~
- ~~复杂的分析计划~~

#### 2. 元数据与业务数据分离

**平台数据库**：

- 用户信息
- 数据源配置
- Schema 快照
- 查询历史
- Dashboard

**用户数据库**：

- 真实业务数据

**原则**：平台绝不迁移业务数据。

#### 3. 安全第一

所有 SQL 必须经过校验：

- 只允许 SELECT 查询
- 禁止危险操作（DROP/DELETE/UPDATE）
- 自动添加 LIMIT
- 超时控制

### 核心流程

#### 用户发起分析请求

```text
1. 用户输入: "分析最近30天销售趋势"
          ↓
2. API 接收请求
          ↓
3. Schema Service 提供数据库结构
          ↓
4. AI Service 生成 SQL
          ↓
5. SQL Validator 校验安全性
          ↓
6. Query Engine 执行查询
          ↓
7. 自动推断图表类型
          ↓
8. 返回结果给前端渲染
```

## 四、模块职责

| 模块 | 职责 | 输入 | 输出 |
| :--- | :--- | :--- | :--- |
| Connection Service | 管理数据库连接 | 连接配置 | 连接状态 |
| Schema Service | 发现数据库结构 | 连接ID | Schema JSON |
| AI Service | 理解需求，生成 SQL | 用户问题 + Schema | SQL 语句 |
| SQL Validator | 校验 SQL 安全性 | SQL | 校验结果 |
| Query Engine | 执行 SQL 查询 | SQL | 查询结果 |
| Chart Inference | 自动推断图表类型 | 查询结果 | 图表配置 |
| Dashboard Service | 管理仪表板 | 组件配置 | 仪表板 |

## 六、设计亮点

1. **简洁架构** - AI 直接生成 SQL，避免过度设计
2. **Schema 感知** - 自动发现数据库结构，AI 能理解业务语义
3. **安全校验** - 所有 SQL 经过白名单校验，防止危险操作
4. **自动推断** - 根据查询结果自动推荐图表类型
5. **可审计** - 所有 AI 生成的 SQL 都可追溯
